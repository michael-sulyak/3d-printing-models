# Printable 3D Models

This repository contains a collection of **3D models designed for 3D printing**.

Each folder represents a **small, self‑contained project**, usually focused on a
single part or simple assembly.

---

## Structure

- One project per folder.
- Source CAD files when available.
- Optional preview images and notes.
